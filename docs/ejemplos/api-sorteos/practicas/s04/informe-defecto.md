# Informe de defecto

| Campo | Valor |
|---|---|
| ID | DEF-.. |
| Título | Qué falla, en una frase |
| Requisito y caso | REQ-.. · CP-.. |
| Versión y entorno | Candidata 1.0.0 · codespace (puerto 3001) |
| Fecha y usuario de prueba | |
| Pasos para reproducir | 1. … 2. … |
| Resultado esperado | Código, cuerpo y, si aplica, cabeceras (según el contrato) |
| Resultado obtenido | Lo que devolvió la API |
| Evidencia | Petición (o curl) y respuesta completas, o el informe de ReadyAPI |
| Gravedad | Alta / media / baja, y por qué |
| Estado | Nuevo |

No pegues tokens reales en un informe de defecto: si hace falta, pon `Bearer <token de ana>`.
